# 全能工具箱

纯前端的一站式工具集：**文档工具**（Word/PDF 互转、压缩、页面排序、标注编辑）、**图片工具**、**压缩解压**、**拾色器**。**所有处理均在浏览器本地完成，文件不会上传到任何服务器。**
支持浅色 / 深色主题（首页右上角切换，自动记忆，默认跟随系统）。

## 功能

顶部导航分为四大工具：**📄 文档工具**（内含格式转换 / 文档压缩 / 页面排序 / 文档编辑四个子模式）、**🖼️ 图片工具**、**📦 压缩解压**、**🎯 拾色器**。

### 1. 格式转换（Word ↔ PDF，文档工具内）
- **.docx → PDF**：一键直接下载，**矢量文字输出**（对齐桌面办公软件的导出质量）——文字从渲染 DOM 逐字符测量定位后以内嵌字体真矢量写入，任意缩放清晰、可选中复制、体积小；粗体使用独立粗体字重，斜体做剪切变换；表格线 / 底纹 / 图片等图形由浏览器渲染引擎按原版式输出（隐藏文字后截取底图）；列表编号（CSS counter）自动具象化为真实文字，不会丢失；字体不支持的生僻字符自动回退为栅格显示，保证不缺字；
- **.pdf → Word**：富格式还原——逐段还原**字号、粗体、斜体**（从嵌入字体名推断），推断**居中 / 右对齐**，**提取内嵌图片**按原位置回填（全页背景图自动剔除），保留分页，兼容带 /Rotate 的旋转页面；扫描件（纯图片 PDF）无法提取文字，会给出明确提示；
- 旧版二进制 `.doc` 暂不支持，界面会提示先在 Word 中另存为 `.docx`。

### 2. 文档压缩（先看效果再压缩）
- 四档预设：**轻度压缩**（150 DPI / 85%）、**均衡压缩**（120 DPI / 70%，推荐）、**极限压缩**（90 DPI / 50%）、**无损优化**（重写文件结构，保留文字层）；
- 支持**自定义参数**（分辨率 72–200 DPI、图像质量 30–95%）；
- 「生成效果预览」给出**预计压缩后大小与节省比例**，并以第 1 页做**原始 / 压缩后并排对比**，确认清晰度后再压缩。

### 3. 页面排序
- 全部页面缩略图，**拖动即可调整顺序**（标注「原第 N 页」与当前位置）；
- **区间成组（模块）**：把第 a ~ b 页设为一个可命名的**模块**（如「中文版」「英文版」），模块以彩色卡片呈现、内含页面缩略图；**拖动模块卡片即可与其他模块/散页整体交换顺序**——典型场景：说明书 1-5 页中文与 6-10 页英文互换；
  - 先后点击两张缩略图可快速填入起止页；模块名称可随时点击修改；「解散」按钮让页面在原位变回散页；
  - 区间与已有模块重叠会被拦截并提示；「重置顺序」同时清除全部模块；「倒序排列」按模块/散页为单位倒排（模块内部页序不变）；
- 支持**删除页面**（散页与模块内均可，右上角 ×）；导出为 `原文件名-重排.pdf`；
- **显示与预览**：缩略图大小三档可调（小/中/大，自动记忆）；缩略图悬停点 🔍（模块内小图直接点击）可**放大预览**——按需高清渲染，支持 ← → 按当前顺序翻页、Esc 或点击空白处关闭。

### 4. 文档编辑（PDF 标注）
- 八种工具：**马赛克**（打码）、**矩形框**（画出某区域）、**高亮**、**直线**（划线/下划线/删除线）、**手绘**、**遮盖**、**文字**（改文案 = 遮盖原文 + 输入新文案）、**拾色器**（点击页面取色，自动设为当前标注颜色并切回上一工具）；
- 颜色、线条粗细、字号可调；**撤销 / 重做**（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z）、清除本页；多页独立编辑，页间自由切换（并发翻页有代际保护，不会错位）；
- 导出两种模式：
  - **默认（矢量叠加）**：标注直接写入原 PDF 页面，原文字层保持可选中，中文文字以内嵌字体写入；
  - **扁平化已编辑页**：将已编辑页整页转为图片，**彻底移除被马赛克/遮盖内容的原始文字**（防止被复制提取）——首次打码/遮盖时自动勾选，可取消；
- 导出取状态快照并加互斥锁：导出期间的编辑不影响本次输出，换文件会被暂时拦截；
- 兼容带 /Rotate 旋转属性的页面（坐标经 pdf.js viewport 逆映射，马赛克补丁按页面旋转预旋转）。

### 5. 图片工具
共享同一张「工作图」，四个功能可**链式操作**（如：裁剪 → 加水印 → 压缩导出），每一步可撤销（最多 10 步）、可重置为原图；支持拖入 / 粘贴（Ctrl+V）/ 选择图片，超大图自动压至 6000px 内。

- **格式转换**：PNG / JPEG / WebP 互转，质量可调，实时预估输出大小；JPEG 透明区域自动填充白色；
- **图片压缩**：质量（20–95%）+ 尺寸缩放（10–100%）双维度，实时显示「原始 → 预计大小 · 节省 %」；
- **图片裁剪**：画布拖拽框选，四角手柄调整大小、选区内拖动移动，比例预设（自由 / 1:1 / 4:3 / 16:9 / 3:4 / 9:16）；
- **水印**：
  - *添加*：文字水印实时预览——内容 / 大小 / 颜色 / 透明度 / 旋转角度，全屏斜向平铺或九宫格单点定位；
  - *移除*：框选水印区域后一键修复——「平滑填充」按周边像素加权插值（适合纯色 / 渐变背景），或「马赛克」遮盖（适合复杂背景）；可多次框选逐个处理。

### 6. 压缩 / 解压
- **压缩打包**：拖入多个文件或**整个文件夹**（递归保留目录结构，也可点击选择文件夹），可多次追加、逐个移除；压缩级别三档（快速 / 标准 / 最大）；打包为 ZIP 并显示「原始合计 → 压缩后 · 节省 %」，打包过程带进度；
- **解压**：支持 **.zip**（JSZip）、**.gz**（浏览器原生 DecompressionStream）、**.tar** 与 **.tar.gz / .tgz**（内置极简 tar 解析器，兼容 GNU 长文件名与 PAX 扩展头）；
  - 文件清单展示路径与大小，单个文件点「下载」即取；
  - 「全部解压到文件夹」通过 File System Access API 按原目录结构写入所选本地文件夹（Chrome / Edge；含 zip-slip 路径清洗），其他浏览器退化为逐个下载；
  - 中文文件名乱码自动修复（严格 UTF-8 优先，失败回退 GBK，兼容 Windows 中文压缩包）；加密压缩包会明确提示暂不支持。

### 7. 拾色器
- **图片取色**：拖入 / 粘贴（Ctrl+V，截图直接贴）/ 选择图片，鼠标移动显示**像素级放大镜**（中心十字 + 实时色值），右侧面板 HEX/RGB/HSL **悬停实时刷新**，点击才提交并计入历史；超大图自动压至 4096px 内；
- **截屏实时取色**：基于 Screen Capture API，把所选屏幕 / 窗口画面截取到取色画布上（截取一帧后立即停止共享），移动鼠标即可**实时显示色值**——弥补系统吸管无法向页面实时回传颜色的限制；
- **快速取色**：浏览器原生 EyeDropper 系统吸管（Chrome / Edge 95+），自带放大镜，适合快速单次取色；
- **色值面板**：HEX / RGB / HSL 三种格式一键复制；支持手动输入 HEX（含 3 位缩写）反查；
- **取色历史**：最近 18 个颜色，点击回填，localStorage 记忆；
- 文档编辑器工具栏中另有内置 🎯 拾色器，可直接吸取 PDF 页面上的颜色。

## 运行

任何静态文件服务器都可以，例如：

```bash
cd FileTool && python3 -m http.server 8642
```

然后访问 <http://localhost:8642>。也可以直接部署到 Nginx、GitHub Pages、OSS 等任意静态托管。

> 直接双击 `index.html`（file:// 协议）在多数浏览器中也能运行，但 pdf.js 会退化到主线程解析，速度较慢，推荐使用本地服务器。

```
FileTool/
├── index.html          # 页面结构（含主题预加载脚本）
├── css/style.css       # 样式（CSS 变量主题化，浅色/深色）
├── js/app.js           # 转换 / 压缩 / 排序 / 主题 + 共享工具（字体、下载、进度等）
├── js/editor.js        # 文档编辑器（标注、撤销重做、拾色器、两种导出模式）
├── js/picker.js        # 拾色器（图片/屏幕取色、色值转换、取色历史）
├── js/image.js         # 图片工具（格式转换、压缩、裁剪、加/去水印）
├── js/archive.js       # 压缩/解压（ZIP 打包、zip/gz/tar/tar.gz 解压）
├── js/subset.js        # 运行时 TrueType 子集器（导出 PDF 时按用字裁剪嵌入字体）
├── vendor/             # 本地化的第三方库与字体（无 CDN 依赖，可离线使用）
│   ├── pdf.min.js / pdf.worker.min.js      # pdf.js 3.11（解析与渲染 PDF）
│   ├── pdf-lib.min.js + fontkit.umd.min.js # pdf-lib 1.17（生成/标注 PDF）+ 字体嵌入
│   ├── NotoSansSC-CN.ttf                   # 中文字体（构建期预裁剪，见下）
│   ├── docx-preview.min.js + jszip.min.js  # 渲染 .docx / 生成 .docx 包
│   ├── html2canvas.min.js                  # DOM 转位图（docx → PDF）
│   └── Sortable.min.js                     # 缩略图拖拽排序
└── samples/            # 测试样例（sample.pdf 6 页 / sample.docx 中英混排）
```

## 技术说明

- **中文字体嵌入**：`NotoSansSC-CN(-Bold).ttf` 为构建期预裁剪的 TrueType（GB2312 + ASCII；粗体按需加载）。运行时先经**自研 TTF 子集器**（`js/subset.js`）裁剪到文档实际用字再整体嵌入——pdf-lib/fontkit 自带的 `subset:true` 会产出损坏字体（已用 Quartz 验证），不能使用；自研子集器重建 cmap(fmt4)/glyf/loca/hmtx 并闭包复合字形，fontTools 与 Quartz 双重验证正确。含中文文字的导出 PDF 体积从 MB 级降至 **几十 KB 量级**（如 rich 示例 4.7MB → 113KB，对齐桌面办公软件）；子集化失败自动回退整体嵌入；
- `.docx` 由 JSZip 手工组装最小 OOXML，已验证可被 Word 与 macOS 原生解析器打开；
- Word→PDF 矢量文字：按**码点**级 Range 逐字符测量，与嵌入字体的预测步进宽度比对、偏差超过 0.9px 即重新锚定分段，两端对齐 / 字距拉伸下也不漂移；基线用 canvas `fontBoundingBoxAscent` 按元素实际字体精确换算；
- 编辑器坐标：canvas（2× 渲染）↔ PDF 用户空间经 `viewport.convertToPdfPoint` 互转，天然兼容旋转页与非零 MediaBox；画布坐标在源头钳制，越界拖拽不会造成打码区域与导出错位；
- 长任务通过 `MessageChannel` 让出主线程且 pdf.js 渲染使用 `intent: 'print'`，标签页切到后台也不会被节流卡住；
- 主题以 CSS 变量实现，`<head>` 内联脚本在首屏前应用已存主题避免闪烁；
- 自适应移动端（画布 `touch-action: none`，触屏可直接绘制标注；多指触摸有 pointerId 防护）。
